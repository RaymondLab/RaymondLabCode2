# RaymondLabCode2

## Pre-requirements

- Spike2 version >=10.19 (this is version required for running Spike2 protocols)


## Install the `uv` Python package and project manager and sync

1. Follow the "Standalone installer" instructions on the official website: `https://docs.astral.sh/uv/getting-started/installation/`
2. FULLY EXIT every terminal instance (including any open windows of Visual Studio Code).
3. Verify in a freshly launched terminal: `uv --version`
4. Run `uv sync` and wait for it to create the environment. 
5. Close the terminal window. The `raymondlabcode2` environment should automatically activate upon re-opening a terminal window, (otherwise something likely went wrong).
